## 数据支持

| 数据类型 | 最大获取量 |
|----------|-----------|
| 天气数据 | 30天 |
| 小时数据 | 7天 |
| 分钟降水 | 2小时 |
| 空气质量 | 24小时 |
| 预警信息 | 实时 |
| 天气指数 | 完整 |

## 核心功能

- **长期存储** - 天气数据本地缓存，支持 30 天数据存储
- **智能预测** - 小时天气智能预测，基于日数据推算
- **分钟降水** - 未来 2 小时分钟级降水预报
- **多城市** - 支持添加多个城市，城市排序
- **多种布局** - 多种主页布局样式适配不同设备
- **动态背景** - 根据天气和日出日落变化的动态背景
- **动画支持** - 完善的页面切换和交互动画效果
- **天气预警** - 实时天气预警推送和详情查看
