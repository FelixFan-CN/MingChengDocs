# 永昼天气 Eternal 隐私政策  
生效日期：2026 年 1 月 3 日  
服务域名：​ api.b4qaq.cn  
运营主体：​ MingChengNetworkStudio（铭诚网络工作室）  
本政策适用于永昼天气 Eternal（下称"本应用"）通过调用铭诚 API 所涉及的个人信息处理行为。本应用承诺按照国家法律法规及相关协议，保护用户个人信息安全。请在使用本应用前仔细阅读本政策。  

## 1. 信息收集与使用

为向您提供天气服务，本应用可能在调用铭诚 API 过程中收集以下信息：

### 1.1 位置信息

当您开启设备定位并授权后，为提供基于位置的天气服务，本应用会获取您的位置信息（包括 GNSS、基站等方式生成的经纬度坐标），并调用铭诚 API 获取相应天气数据。

> **特别说明：** 基于 Vela 系统特性，定位功能在应用运行期间可能无法随时由用户主动关闭，我们会将您的经纬度坐标传输至铭诚 API 服务器，用于查询对应城市位置信息。有关位置信息的进一步处理规则，请参阅《铭诚 API 隐私政策与使用条款》。

### 1.2 设备信息

包括设备标识符（如设备型号，设备唯一 ID）、XiaomiVela 系统版本、网络制式等，用于激活验证、服务运行保障及统计信息。该信息会在加密后上传至本应用及铭诚 API 的服务器。

上述信息中，部分由本应用直接处理，部分为调用铭诚 API 所必需。铭诚 API 对数据的处理受其隐私政策约束。

## 2. 信息存储与保护

本应用收集的个人信息（包括位置信息、设备信息）将由铭诚 API 服务器存储。其他非个人信息数据（如用户设置、缓存数据等）将存储在您的设备本地。

本应用将采取合理的安全措施（如加密传输）保护信息，防止未经授权的访问、泄露或损坏。

涉及铭诚 API 调用的数据，其存储与保护同时遵循铭诚 API 的隐私政策及安全要求。

## 3. 信息共享与披露

本应用不会与无关第三方共享您的个人信息，但以下情况除外：

### 3.1 为实现服务功能

为调用铭诚 API 实现服务功能，向铭诚 API 提供必要信息（如位置、设备信息）。

### 3.2 法律法规要求

根据法律法规、诉讼或政府主管部门要求。

### 3.3 保护权益所必需

为保护本应用、用户或公共利益的安全。

铭诚 API 可能将部分信息与其授权合作伙伴共享，具体规则见其隐私政策。

本应用可能会将您的信息用于制作统计数据，但不会与其他人员共享。

## 4. 免责声明

本应用基于 Vela 设备及铭诚 API 开发，受限于设备性能、信号接收、网络环境等因素，不保证服务的连续性和定位的精确性。

## 5. 政策更新

本政策可能随服务调整而更新，更新后将通过官方网站发布。继续使用本应用即表示同意更新后的政策。
