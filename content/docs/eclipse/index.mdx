**Eclipse 星语** 是一款运行在 Vela 智能穿戴设备上的 AI 对话客户端，支持多模型接入、结构化工具调用、隔离脚本环境与全局记忆。

## 应用概述

Eclipse 星语（Eclipse）是在手表 / 手环上直接与大语言模型对话的客户端。它支持直连 OpenAI 兼容接口或通过官方中转网关访问，并将网络能力、文件系统、设备控制等封装成**结构化工具**交给 AI 调用，在确保安全的前提下让 AI 真正"动起来"。

## 核心功能

### AI 对话

| 功能 | 描述 |
|------|------|
| 多模型接入 | 支持直连 OpenAI 兼容接口，模型列表实时拉取 |
| 官方中转 | 支持经官方中转网关访问（密钥不明文落盘） |
| 自定义服务商 | 可配置自己的服务地址与登录密钥 |
| 真实用量统计 | 直连模式下直接读取服务端的真实用量，不估算 |

### 结构化工具调用

| 功能 | 描述 |
|------|------|
| 文件读写 | 读取、创建、列出、删除文件（默认限于本会话工作区） |
| 文件工作区 | 每个会话独立工作区；访问工作区外文件需用户额外审批 |
| 设备控制 | 震动、亮度 / 音量调节、查看电量 / 定位 / 时间 / 设备信息 |
| 天气查询 | 查询指定城市天气 |
| 会话命名 | 可让 AI 为会话命名；每 5 轮对话后自动更新标题 |
| 审批模式 | 手动 / 智能 / 绕过三种授权粒度，高风险操作橙色提醒 |

### 全局记忆

AI 拥有跨会话持久生效的长期记忆能力：

- 每个新会话的第一条消息会自动读取记忆，AI 也可自行判断主动读取
- 自动记录值得长期记住的用户偏好与事项
- 记忆内容受保护不可删除，但可随时由 AI 更新
- 支持三层开关：全局总开关、新会话默认值、单会话开关，并可一键清空

### 隔离脚本环境

| 模式 | 行为 |
|------|------|
| 受限（默认） | 静态扫描危险代码，限制死循环与定时器，仅注入白名单能力 |
| 完全 | 跳过静态拦截，供需要复杂脚本的场景使用（仅对当前会话生效） |

### 输入体验

内置多套键盘布局，支持完整的文字输入。

## 隐私与安全

- 登录密钥仅保存在设备本地
- 官方中转请求不落盘明文密钥，动态拼接复合密钥
- 自定义服务商的密钥明文保存在本地配置中
- "绕过" + "完全"同时开启等于 AI 全权访问，界面以橙色醒目提示
- 记忆内容受硬保护，AI 无法删除
- 文件默认按会话隔离在工作区内，跨工作区访问一律需要用户确认
- 应用数据目录（密钥、会话数据）对 AI 完全不可见

完整的信息处理说明见[隐私政策](./privacy)。
