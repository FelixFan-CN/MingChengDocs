# Eclipse 隐私政策

| 项目 | 内容 |
|------|------|
| 生效日期 | 2026 年 9 月 1 日 |
| 服务域名 | `api.b4qaq.cn` |
| 运营主体 | MingChengNetworkStudio（铭诚网络工作室） |

本政策适用于 **Eclipse 星语**（下称"本应用"）通过调用铭诚 API 及第三方 AI 供应商所涉及的个人信息处理行为。本应用承诺按照国家法律法规及相关协议，保护用户个人信息安全。请在使用本应用前仔细阅读本政策。

<Callout type="info">
本页内容与应用首次启动时展示的协议一致。首次启动需同意后方可继续使用。
</Callout>

## 1. 信息收集与使用

为向您提供 AI 对话服务，本应用可能收集和处理以下信息：

### 1.1 设备信息

包括设备标识符（设备型号、设备唯一 ID、序列号）、XiaomiVela 系统版本、屏幕类型、网络制式等，用于激活验证、服务运行保障及统计。该信息会在加密后上传至铭诚 API 服务器。

### 1.2 对话内容

您与 AI 助手的对话消息（包括文本、工具调用指令与结果）会发送至您当前选择的 AI 供应商进行处理：

- 使用**官方中转**时，对话经铭诚 API 转发至上游 AI 模型
- 使用**自定义供应商**时，对话直接发送至您配置的第三方接口

<Callout type="warn">
对话内容在传输过程中使用 HTTPS 加密，但 AI 供应商对其接收的数据的处理受其各自的隐私政策约束，本应用无法控制第三方供应商对数据的存储和使用。
</Callout>

### 1.3 工具调用信息

当您或 AI 触发工具调用（如读写文件、控制设备亮度 / 音量 / 震动、查询定位等）时，相关操作在您的设备本地执行，执行结果会作为对话上下文的一部分发送给 AI 供应商。

<Callout type="info">
定位信息仅在 AI 调用 `get_location` 工具时才读取，且读取结果会随对话上下文发送给当前 AI 供应商。不使用该工具时不会获取位置。
</Callout>

### 1.4 本地存储数据

以下数据存储在您的设备本地：

- 对话历史（会话列表与消息记录）
- 供应商配置（名称、服务地址、登录密钥、模型列表）
- 您与 AI 创建的文件
- 应用设置与统计数据
- 全局记忆内容

### 1.5 网络连接

本应用支持三种网络模式：设备原生网络、eSIM 以及 AstroBox 桥接代理。桥接模式下，网络请求通过手机端 AstroBox 应用转发，AstroBox 端的数据处理受其隐私政策约束。

## 2. 信息存储与保护

### 2.1 设备本地

对话历史、供应商配置、用户文件等数据存储在设备本地，您可随时在应用内删除（撤销授权、清除数据或删除单个文件）。

### 2.2 服务器存储

设备激活信息（设备标识符、APIKey）存储于铭诚 API 服务器，用于服务鉴权与用量统计。AI 对话内容由各 AI 供应商处理和存储，具体规则见其各自的隐私政策。

### 2.3 安全措施

本应用使用 HTTPS 加密传输所有网络请求，设备激活采用 RSA 签名验证机制。APIKey 等敏感信息存储在设备本地应用私有目录。

### 2.4 应用内的数据边界

除上述传输与存储策略外，本应用在设备内部也设置了访问边界：

| 边界 | 说明 |
|------|------|
| 文件按会话隔离 | AI 对文件的读写默认限制在当前会话的工作区内；访问工作区外的文件需您确认，该确认独立于审批模式 |
| 应用数据目录 | 供应商密钥、会话数据等应用自身数据对 AI 完全不可见，任何情况下都不允许 AI 读写 |
| 全局记忆 | 内容受保护，AI 无法删除；记忆关闭后应用不再向模型下发记忆相关能力 |
| 工具调用的授权 | 按您选择的审批模式逐次或自动授权，高风险模式（"绕过" / "完全"）会以醒目标识提醒 |

## 3. 信息共享与披露

本应用不会与无关第三方共享您的个人信息，但以下情况除外：

### 3.1 为实现服务功能

使用官方中转时，为提供 AI 对话服务，向铭诚 API 及上游 AI 模型提供商传输必要信息（对话内容、设备标识符）。使用自定义供应商时，对话内容直接发送至您配置的第三方 API 端点。

### 3.2 法律法规要求

根据法律法规、诉讼或政府主管部门要求。

### 3.3 保护权益所必需

为保护本应用、用户或公共利益的安全。

## 4. 用户权利

- **数据删除**：您可随时在应用内删除对话记录、清除本地数据、撤销设备授权
- **供应商选择**：您可自由选择使用官方中转或自定义第三方供应商（不配置供应商时默认使用官方中转）
- **模型选择**：您可在已配置供应商的模型列表中选择所使用的 AI 模型
