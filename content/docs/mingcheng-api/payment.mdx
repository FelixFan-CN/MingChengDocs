> 模块类型：system

## 获取支付状态

| 项目 | 内容 |
|------|------|
| **API** | `POST /api/v2/payment/status` |
| **说明** | 获取支付系统状态 |

**无需登录**

**返回：**

```json
{
  "status": 200,
  "result": {
    "platform": "aifadian",
    "status": "active",
    "supported": true
  }
}
```

---

## 爱发电 Webhook 回调

| 项目 | 内容 |
|------|------|
| **API** | `POST /api/v2/payment/afdian/webhook` |
| **说明** | 接收爱发电订单回调，处理支付逻辑 |

**无需登录**（由爱发电服务器调用）

**参数：**

| 参数 | 位置 | 必填 | 说明 |
|------|------|------|------|
| 整个 body | body | 是 | 爱发电 Webhook 数据 |

**返回：**

```json
{ "ec": 200, "em": "ok" }
```

<Callout>
此接口返回非标准格式，是爱发电平台要求的响应格式。
</Callout>
