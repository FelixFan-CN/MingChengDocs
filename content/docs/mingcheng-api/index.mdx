# 简介

MingChengAPI 是一个高自由度、开放的第三方快应用 API 服务，为开发者提供设备验证、天气数据、邮件服务、AI 模型中转、AI 任务、设备隧道等功能。
其具有可拓展性强，开发者友好，稳定安全等特点。

## API基础信息

| 项目 | 值 |
|------|-----|
| 基础路径 | `https://api.b4qaq.cn/api/v2` |
| 认证方式 | 设备 APIKey |
| 统一响应格式 | `{ status: 200, result: ..., message: "..." }` |

<Callout type="info">
`message` 字段可选；失败时返回对应 HTTP 状态码与 `{ status: <码>, result: "<错误信息>" }`。
</Callout>

## 权限等级

```
Verify(设备验证) < User(普通用户) < Dev(开发者) < ROOT(超级管理员)
```

初始注册均为User,请联系站长(QQ 525148989或525148989@qq.com)开启Dev权限

<Callout type="warn">
下文的服务模块（天气、邮件、AI 等）均使用设备 APIKey，且应用须在后台启用对应服务后才可调用。
</Callout>

## 简单接入

### 1. 注册账号
进入https://api.b4qaq.cn/ 点击右上角注册，按照提示注册，并使用邮箱激活
### 2. 申请提权
联系QQ 525148989或向525148989@qq.com发送邮件，明确说明需要使用API，需要提权
获得提权后重新登录，即可进入管理后台
