## 核心功能

### 邮件管理

| 功能 | 描述 |
|------|------|
| 邮件列表 | 按时间排序显示邮件，支持分页加载 |
| 邮件详情 | 长邮件自动分页 |
| 搜索邮件 | 标题搜索，支持搜索历史记录 |
| 星标邮件 | 标记重要邮件，快速筛选查看 |

### 邮件操作

| 功能 | 描述 |
|------|------|
| 撰写邮件 | 支持收件人、主题、正文编辑 |
| 回复/转发 | 快速回复或转发邮件 |
| 删除邮件 | 支持本地缓存和云端邮件删除 |

### 离线支持

| 功能 | 描述 |
|------|------|
| 邮件缓存 | 将邮件缓存到本地，支持离线查看 |
| 附件预览 | 图片附件可直接预览显示 |
| 搜索历史 | 保存搜索记录，快速访问 |

### 输入体验
在NEORUAA的Vela_input_method基础上额外添加了：
| 功能 | 描述 |
|------|------|
| 光标操作 | 上下左右移动，支持选区操作 |
| 剪贴板 | 复制、粘贴、剪切、全选(应用全局) |

### 账户与设置

| 功能 | 描述 |
|------|------|
| 多账户管理  支持多个邮箱账户，一键切换 |
| 服务器配置 | 自定义 IMAP/SMTP 服务器 |
| 分页设置 | 自定义列表和正文的分页数量 |

## 隐私与安全

- 邮箱密码仅存储在本地设备
- 支持授权码登录（无需暴露真实密码）
- 数据传输使用 SSL/TLS 加密
- 符合《[腕上信驿 WearPost 隐私政策](./privacy)》
